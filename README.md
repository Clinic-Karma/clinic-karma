# 🏥 Clinic Karma — Healthcare Management System

Clinic Karma is a full-stack web application built using **React (Vite)** and **Node.js (Express)** with a PostgreSQL database.  
It supports multiple user roles such as patients, doctors, receptionists, branch managers, and top managers.

---

## 🚀 Tech Stack
**Frontend:** React + TypeScript + Tailwind + Vite  
**Backend:** Node.js + Express + PostgreSQL  
**Deployment:** Vercel (frontend) + Render (backend)  
**CI/CD:** GitHub Actions automated pipeline

---

## ⚙️ Features
- User authentication with JWT
- Role-based dashboards
- Appointment booking system
- Patient records & messaging
- File upload (lab reports)
- Centralized API design with controllers and routers

---


---

## 🧠 Deployment Workflow
1. Push to `main` → triggers GitHub Actions CI
2. Build and test React + Express
3. Auto-deploy frontend → Vercel
4. Auto-deploy backend → Render
